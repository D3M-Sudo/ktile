# Code of Conduct

K-tile aims to provide a respectful, constructive and harassment-free project environment regardless of experience, identity, background or viewpoint.

Expected behavior includes respectful technical discussion, actionable feedback, welcoming good-faith questions, respecting privacy and focusing criticism on work rather than people.

Harassment, personal attacks, discrimination, threats, deliberate intimidation, doxxing and sustained disruptive conduct are unacceptable.

Report conduct concerns privately to the repository maintainers through a contact channel listed on the owner's GitHub profile. Include relevant context without republishing private information. Maintainers will review reports and determine an appropriate response.

This policy applies to repository issues, pull requests, discussions, code review and project-related communication.
